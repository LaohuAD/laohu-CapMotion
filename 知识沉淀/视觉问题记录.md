# 视觉问题记录

本文件记录已经发现的不满意视觉问题，避免后续重复出现。

## 已知问题

- 旧试验画面只是第一版，不代表最终视觉标准。
- PPT 本身不够美观，不能直接作为项目审美标准。
- 页面信息如果只是口播摘要，会显得没有额外价值。
- 画面过像通用 AI PPT，会削弱老胡内容的专业感。
- 文字过多会影响口播视频的观看体验。
- 当前第一版中部分画面偏“摘要化”，还没有充分提供口播之外的执行模板、判断标准和复盘动作。
- 只展示流程名不够，流程类画面应该同时展示每一步的产物。
- 用户说“更炫酷”时，不应理解为堆粒子和光效，而应理解为“更像 AI 内容系统正在运行”：状态栏、节点推进、控制台、指标面板、风险动作、模板字段等。
- 浅色课程控制台容易显得像 PPT；AI 自媒体博主包装可以使用深浅结合的科技工作台，但必须保持可读性和信息层级。

## 以后检查

- 这一屏是否有“课程讲义感”？
- 是否像真的在帮观众建立认知结构？
- 是否能看出和口播之间的互补关系？
- 是否有明显模板味或廉价感？
- 这一屏是否能回答“观众听到这里会卡在哪里”？
- 这一屏是否像一个内容生产系统，而不是普通卡片摘要？

### 文字卡片型 MG 容易显空

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：如果 1920x1080 画面只有大标题、两张大卡片和少量文字，即使有动效，也会显得空，不够像高质量知识讲解视频。

修正方式：

- 核心场景增加图解结构：箭头、流程、矩阵、漏斗、时间轴、产物流转、风险映射。
- 不靠堆长段文字增加密度，而是增加节点、关系、判断标准和动作说明。

后续规则：遇到“画面空”的反馈，优先问这页缺什么关系图，而不是只加文字或放大卡片。

### 中文标题不能交给浏览器自然断行

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：中文标题如果完全依赖容器宽度换行，容易在不自然位置断开，显得不专业。

修正方式：

- 人工选择换行点。
- 优先在逗号、顿号、冒号、完整短句、并列结构处断行。
- 不拆开核心概念、动宾结构、数字单位。

后续规则：每次制作前检查标题断行，关键标题必要时用手工 `<br />`。

### 横版视频缩到竖屏手机后容易看不清

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：横版 1920x1080 画面在电脑预览中可读，但用户实际可能在竖屏手机信息流里观看横版视频。此时小字、稀疏卡片和没有占满的画面会显得空，重点信息也不够突出。

修正方式：

- 保持横版母版，但把手机缩小观看作为质检场景。
- 放大标题、节点名、流程动作、判断标准等关键文字。
- 次要说明可以更短、更少，不能让小字承担核心理解。
- 增加流程图、关系图、路径图、漏斗、矩阵、箭头、时间轴、风险映射等图解结构，让画面更满、更有重点。

后续规则：遇到“横版但要适配手机观看”的作品，先检查可读性和信息占用率，再检查动效炫酷程度。

### 空容器和占位横线会让画面显得没做完

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：用户截图指出多个红框区域显得空，包括卡片中部没有内容、右侧决策区未显示、选题卡字段只有横线、媒体卡下方空白、记录闭环区域没有内容、底部进度条遮挡文字等。这类画面会让观众感觉“标题出来了，但主体没有讲完”。

修正方式：

- 卡片中部要补例子、标签、图解、状态灯或小型关系线，不能只留空。
- 可填写模板不能只有下划线，应从口播稿或原始素材里提取示例词填入。
- 如果内容被全局动画隐藏，必须在对应场景节拍里 reveal，不能出现空面板。
- 底部进度条和装饰线不能盖住文字；必要时降低层级或增加安全距离。
- 适合动态图解的区域，直接建立完整 Remotion 批注，再选择路径、折线、雷达图等组件。

后续规则：质检时必须专门检查“红框空白感”，不要只看是否通过 lint / inspect。

### 反馈标注不能被照搬成设计元素

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：用户在截图中手画红线只是为了指出“这里可以做动态图解 / 这里太空”，实现时如果把这类随手画的线直接变成规整画面元素，会显得死板，还可能遮挡正文。

修正方式：

- 先判断标注意图：是说空、遮挡、错色、换行难看，还是希望有趋势 / 关系 / 动效。
- 再按画面语义重新设计，不照搬红线形状。
- 任何线条、箭头、曲线都必须避开文字和关键标签，不能为了动效破坏可读性。

后续规则：截图标注只代表问题位置和方向，不代表最终图形样式。

### 进度条应进入顶部安全区

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：底部进度条容易遮挡正文、卡片底部标签或结论条，尤其是横版缩到手机观看时更明显。

修正方式：

- 全局进度条优先放在顶部 HUD 附近的空区。
- 顶部进度条要细，不抢标题层级。
- 预览时检查开场页、卡片页和结尾页是否仍有正文被压住。

后续规则：进度条是导航辅助，不是画面主体，不能牺牲内容可读性。

### 媒体卡中段不能空着

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：视频形式卡如果只有一个手机框、标题、短句和底部标签，中间区域会显得空，像模板还没填完。

修正方式：

- 手机框内部补相关视觉：歌词条、屏幕行、素材网格、人物点、风险标签等。
- 卡片中段补“适用场景 / 产出动作”这种短信息，不靠长段文字填满。
- 卡片之间颜色和透明度要一致，强调用边框、发光或局部高亮，不用整体半透明把某张卡变“灰”。

后续规则：媒体卡要同时承担“图像示意 + 操作判断”，不能只做分类标签。

### Remotion 贴片叠加会造成重复和遮挡

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：本轮把 Remotion PNG 阶段图直接叠加在已有基础图解上，导致内容重复、重叠，影响观看；阶段图停留时间也偏短，整体效果下降。

修正方式：

- 当前作品已撤掉效果较差的 Remotion 可见调用，回到基础主画面。
- 后续 Remotion 不能作为“额外贴片”覆盖已有画面。
- 使用 Remotion 前必须先设计替换范围：删掉或降权基础画面的对应图解，让 Remotion 成为该区域主表达。
- Remotion 片段必须有足够停留时间，不能只闪几秒；复杂图解至少要覆盖口播的主要解释窗口。
- 接入前要做 A/B 快照对比：确认 Remotion 版确实比基础画面更清楚、更丰富、更好看，再替换。

后续规则：Remotion 是解释工具，不是叠加装饰；没有明显增益时，不增加动画覆盖。

### 观众可见文案不能像工程标签

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：开场页左侧出现 `BROKEN MODE`、`发布断点`，右侧用孤立的 `7` 和 `下一条` 做指标，会让观众理解成本变高，像内部结构标记而不是讲解画面。

修正方式：

- 英文模式名改成中文讲解标签，例如“错误做法：只停在生成”。
- 抽象节点改成观众能理解的动作，例如“点生成 / 拿到歌 / 直接发 / 没人看完”。
- 孤立数字要补语义，例如“7 步 / 从想法到复盘”。
- 结论条要直接收束观点，例如“歌曲只是素材，跑完内容闭环，才有增长机会”。

后续规则：画面文案优先服务观众理解，不使用只方便制作方理解的工程标签。

### 半边空白和卡片内空白会让画面像没排完

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：开场页右侧指标卡只有左上角少量文字，剩余区域大面积空着；这类构图即使文案改好了，也会显得画面没用满、重点不够强。

修正方式：

- 如果内容少，就把核心信息做大并居中，不要贴在左上角。
- 卡片内部可以用上下结构、居中数字、短解释、状态词来撑满，而不是靠小字占角落。
- 左右布局要检查视觉重量：左边信息块、右边图解或指标必须都有明确主体。
- 空白可以保留呼吸感，但不能变成“半边没人用”的空。

后续规则：质检时单独检查“半边空白 / 卡片内空白”。出现这种情况时，优先重排版，再考虑补内容。

### 红框空白要补可读细节，不是只补一句话

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：用户再次指出开场页左侧卡片内部有明显空白。虽然已经加入“缺的不是音乐，是内容动作”的说明，但如果细节只集中在卡片下半区，顶部和中部仍然会显得像没排完。

修正方式：

- 被用户红框指出的空白区，要优先补充真实语义内容：步骤、例子、缺失项、判断标准或产出动作。
- 补文字时不能只加一句泛泛解释，应拆成观众能看懂的短项，例如“钩子 / 画面 / 互动 / 复盘”。
- 卡片应形成上中下完整信息层：问题判断、具体缺失、错误路径或后果。
- 如果补充后仍然显空，要继续重排版，而不是认为“已经有文字了”。

后续规则：看到用户说“空着、空白、给我细化文本进去”时，必须处理具体空白区域的版面占用率和信息密度。

### 自检范围要包括读感、逻辑和关系

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：用户补充指出，自检不能只盯空白，还要看分段、标点、标题、表述完整度、前后冲突和逻辑关系。也就是说，凡是会让观众看着不舒服、理解打折或拿不到价值的地方，都应该纳入修正范围。

修正方式：

- 分段要自然，避免生硬切句。
- 标点要服务停顿和节奏，不要只为了排版。
- 标题要顺口，不能只追求占满容器。
- 文案前后不能自相矛盾，关系链要说清楚。
- 示意图、箭头、节点、图表关系如果没讲明白，就当成画面问题处理。

后续规则：自检时要把“看起来好不好读、好不好理解、好不好记”一起检查，不只是看有没有空位。

### 编辑器残留 HTML 字符串是严重观感问题

出现作品：`作品/001_超级音乐小白流量进阶指南`

问题描述：Scene 03 右下卡片曾出现 `<span class=...>` 这类 HTML 字符串，说明 Studio 编辑或文本替换时把标签当作普通文本写进画面。观众看到这种内容会立刻出戏，也会暴露制作痕迹。

修正方式：

- 每次截图自检时，除了看空白，还要扫一遍可见文字是否有 HTML 标签、CSS 类名、工程字段、data 属性或编辑器残留。
- 复杂富文本不要在 Studio 文本面板里直接改 HTML；需要回到源文件按 DOM 结构修改。
- 画面上的所有文字都必须是观众可读内容，不能出现制作方内部信息。

后续规则：出现 `<span`、`data-`、`class=`、`style=`、`undefined`、`null` 等可见工程文本，优先视为必须立刻修复的问题。
