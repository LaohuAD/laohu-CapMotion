First you need to understand what each one does

The first pass locks in the overall composition
The second pass further refines that composition
My key change to this workflow is in the Sigma values
Normally the first pass produces a fully detailed image
But my first-pass result here is very blurry

I use four steps for the first pass and five for the second
The first pass ends at 0.9231
The second pass starts at 0.9231 and ends at 0
You can think of it as sampling in stages
Everything before 0.9231 is the first pass
The first pass outputs a Latent
which is then resampled by the second-pass sampler
That's the basic logic
The most important point here is
The first-pass output must use the denoised output
The other output will not work
The denoised output is only a preview output
It has not actually finished sampling
It is also different from the direct output
The direct output is nothing but noise
It leaves room for the second pass to continue
Then it goes through latent-space upscaling
