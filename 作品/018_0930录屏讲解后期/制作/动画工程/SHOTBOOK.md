# 018 覆盖动画 SHOTBOOK

**这是一份阶段限定调用下的分镜工作单，不是第二份审稿稿源。** 单元范围、事实材料、底画职责与覆盖窗口来自本作品唯一审稿（`分析/预剪辑审稿.json` revision 47）与冻结 EDL（`制作/剪辑清单.json`），上游只负责卡、运动与实现。

## G0 风格档

- **讲什么**：AI 时代怎么建立自己的判断力；**对谁讲**：会用 AI、但效果不满意时只会换工具的人；**什么口吻**：第一人称复盘，快语速、高信息密度。
- **风格档**：深底 · 单一强调色（青 `#8FE3D1`）· 无衬线黑体 · 中性卡片 · 强调色只标「正在讲的那一项」。
- **样板镜**：s01（用第一单元判定蒙皮、字幕样式、卡的密度与音效电平）。
- **版式节奏表**：本片 19 个单元全部为**角落或全幅覆盖卡**，底画是同一路录屏；轮换在「卡的形态」之间做（对照 / 机制 / 清单 / 大字卡 / 面板），同一形态不连用 3 镜。

## 素材口径（本项目适配）

底画本身就是**录屏证据**——它在四档输入里对应「截图」档，但由 Cap 的底画层承担，不进覆盖资产。
覆盖资产只画**关系与关键词**：1920×1080 / 30fps / 透明底，不含背景、字幕、进度条、人物与音轨。
因此每镜素材行写 `文 · 人`：卡是纯动效文字与图形，人物是底画里的摄像头小窗。

## s02 · 57.46–68.77 · 人人都会用 AI 之后

- 语义：机制
- 覆盖窗口：57.46–68.80 秒（审稿 C012–C014）
- 素材：文 · 人
- 意图：画出「人人都会用 → 信息差变小 → 优势回到自己身上」这条因果链，观众才知道问题为什么落到自己身上。
- 选卡行：机制 → source-converge
- 蒙皮行：source-converge → 去掉原卡白底舞台改透明底 + 0.62 深色压暗；曲线 `#c9c9cf` → `rgba(255,255,255,.22)`；来源胶囊白底描边 → `#272729` 深 tile + hairline；汇聚胶囊与数据包 `#0066cc` → 本片强调色 `#8FE3D1`；汇聚胶囊文字改深色 `#04100E`；字体栈换 Source Han Sans CN VF；viewBox 仍 960×540 而绘制面铺满 1920×1080（等价于原卡 1080p 规格的线 2→4px、胶囊 128×44→256×88、文字 20→40 / 22→44）。**时序 / 缓动 / 几何比例 / 层级未改。**
- 触发对位：`convAt = 6.69` 秒——汇入在成片 65.65 秒收束，正对他问「我跟其他人相比核心优势到底在什么地方呢」。
- 卡自检（照抄 references/cards/source-converge.md 落位自检）：
  - 定妆帧三张：接通完（≈1.5s）三条线全到汇聚点、三个胶囊都在起点；汇入中途（≈2.4s）每个胶囊压在自己那条线上且已明显缩小；居中后（≥4.4s）胶囊 + 说明行包围盒中心居中，偏差 ≤48（960 口径）
  - 擦线开始那一帧画面里不得有任何来源胶囊残留
  - 来源胶囊之间等距、同组同造型；曲线颜色浅于胶囊描边；数据包只有强调色
- 已知坑（照抄，实现后逐条核）：节点直线插值/匀速缩小/线早于节点消失/擦除方向反/结果留在右侧/数据包非整数周期/曲线过深过粗
