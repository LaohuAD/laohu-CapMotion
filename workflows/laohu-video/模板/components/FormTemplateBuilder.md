# FormTemplateBuilder

## 任务

通过字段填写、清单、输入输出和结果生成，让观众能够照着行动。

## Modes

`form-fill` / `checklist` / `input-output` / `result-card`

## 输入边界

- 2-8 个字段或动作。
- 字段名称短，说明写清如何填写或做什么。
- 最终结果卡必须由前面的输入生成，不能是无关口号。

## 适用

选题卡、发布包、工作表、开工清单和操作模板。

## 禁用

没有实际动作或产出时不要把普通列表伪装成模板。

## 质检

字段逐项出现并保持已填写状态；结果区不空；最终完整模板有足够停留时间。
