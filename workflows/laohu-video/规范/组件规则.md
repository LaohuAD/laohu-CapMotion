# 组件规则

本文件是公开动画组件家族的唯一登记表。组件解决信息任务，不按博主行业分类，也不把纯转场、箭头或卡片基础样式登记成公开组件。

代码登记表位于 `模板/remotion-assets/workspace/src/registry/componentRegistry.ts`。本文件与代码必须保持同名；代码 schema 和实际渲染结果优先于文档描述。

## 成熟度

```text
计划：只有用途定义
试验：有实现，尚未经过真实内容验证
可复用：通过 schema、类型、渲染和至少一个真实样例验证
成熟：多条作品使用并得到用户认可
废弃：被新组件替代或长期价值不足
```

当前 12 家族均已完成代码、schema、Studio 注册和默认关键帧渲染；其中 6 个通过作品 001 场景验收，因此状态为“可复用”，其余为“试验”。

共 12 个公开家族、53 个登记模式。模式属于家族，不拆成 53 个独立组件。

另外，代码注册表已有 `EditorialOverlayShell` 编辑叠层壳，含 `progress-rail / evidence-dock / label-stack / value-callout / bridge` 五种模式，说明见 `模板/components/EditorialOverlayShell.md`。上述 12 个语义家族加该壳共 13 个注册入口；它们都不是创作形态上限。作品专属 Composition 可按动画导演转译规范独立注册，不必伪装成这些家族。

## 选择入口

```text
一句强观点、问题、数字 -> KineticStatement
正误、前后、A/B -> CompareTransform
步骤、分支、闭环、产物 -> FlowNodeGraph
中心与模块、层级、包含、网络 -> SystemMap
多个方案要做选择 -> DecisionCanvas
时间推进、版本、里程碑 -> TimelineRoadmap
真实数据、趋势、指标面板 -> DataStoryChart
流失、转化、逐层筛选 -> FunnelJourney
观点需要来源和证据 -> EvidenceBoard
需要观众填写或照着做 -> FormTemplateBuilder
解释截图、软件或页面 -> ScreenExplainer
风险必须对应动作和记录 -> RiskActionLoop
```

若两个组件都合理，优先选择能让观众更快看懂真实关系的一个；不能以“更炫”作为唯一理由。

## 公共输入要求

每个配置至少包含：

```text
component / mode
title
communicationGoal / emotionalTone / informationShape / motionIntensity
stylePreset / renderMode / durationInFrames
items（每项带 source）
```

可选字段：`subtitle`、`conclusion`、`links`、`highlightOrder`、`supportingLabels`、`mediaSrc`、`sourceTimeRange`、`kicker`、`titleLines`。

跨家族呈现字段：

```text
presentation：stage / overlay，默认 stage
placement：left / right / center，叠层按人脸、手势和证据空区选择
accentRole：info / success / warning / danger / technical
stylePreset：editorial-dark 提供中性暗色玻璃叠层，语义色由 accentRole 决定
```

`titleLines` 只在确实需要手工断行和逐行语义色时使用；每行必须是完整意群，`tone` 只能表达主次、成立、警告或否决关系，不能为了热闹随机换色。

当前 `KineticStatement`、`CompareTransform`、`FlowNodeGraph`、`DataStoryChart` 已支持 `overlay`。这不是第 13 个组件家族；信息结构仍由原家族负责，叠层只改变它怎样进入底画安全区。

## 公共质量要求

- 不能丢失输入条目。输入 6 个路线，最终态必须看到 6 个。
- 不能用错误图形暗示关系。2h、24h、72h 是观察窗口时，不画成业绩高低柱。
- 流程边必须回答谁指向谁；矩阵必须给选择依据；风险必须逐行对应动作和留痕。
- 最终态不能被结论条、字幕或安全区遮挡。
- 完整图解不能只闪过几秒。
- 没有真实数据时使用结构和示意标签，不编造数值。
- 组件说明书在 `模板/components/组件名.md`，选定组件后再读取，不一次加载全部说明书。
