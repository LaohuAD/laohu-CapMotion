# 字幕校对与烧录规则

## “修正SRT字幕”固定流程

当用户说“修正SRT字幕”时，执行项目级 `.agents/skills/correct-srt-subtitles/`，流程限定为文字校对，不自动进入字幕烧录：

如果该指令和“粗剪、精剪”一起出现，应把它理解为同一成片流水线的最后一个阶段：粗剪结果进入精剪，精剪结果进入字幕修正，默认只交付最终成片和正式校对 SRT，不分别交付三个阶段版本。单独触发“修正SRT字幕”时，仍只处理当前指定成片的字幕，不自动回到前两个阶段。

```text
读取当前成片的新识别 SRT / 原始 JSON
-> 保留原始识别文件不覆盖
-> 校验格式与时码
-> 逐条检查专名、英文、数字、术语、同音错词、上下文、断句和剪口
-> 确定错误写入字幕修正记录并应用到修正草稿
-> 不确定项保持原文并写入字幕疑难清单
-> 用户确认疑难项
-> 生成正式校对 SRT
-> 复查全部修改点和开头、中段、结尾
```

固定产物：

```text
原始成片 SRT          不改，保留机器识别基线
字幕修正记录.md       记录确定修改、依据和时间码
字幕疑难清单.md       只列需要用户判断的条目
*_修正草稿.srt        只应用确定修改，疑难项保持原文
*_校对.srt            用户确认后生成的可发布字幕
```

字幕修正不是文案改写：口语表达只要语义正确就保留，不把讲述者的真实说法改成另一套书面表达；也不因识别文字看起来重复就再次删除视频内容。

## “字幕的烧录”固定流程

当用户说“字幕的烧录”时，执行项目级 `.agents/skills/burn-subtitles/`。这个流程发生在“修正SRT字幕”之后，只使用与当前成片对应、已经确认的正式校对 SRT：

```text
正式校对 SRT
-> 校验成片与字幕时间轴
-> 横屏画布统一为 16:9：标准 16:9 源画面满屏保留并在画面内叠字；非 16:9 源画面等比保留，再利用画布余量放字幕
-> 按固定思源黑体样式制作中文字幕
-> 中文翻译为简洁自然的英文，制作中文在上、英文在下的双语字幕
-> 新样式先渲染一份双语短预览并抽帧比对
-> 用户确认视觉样式
-> 默认只输出中英双语版；用户明确要求时再输出中文版
-> 解码、流、时长、画面和字幕抽查
```

默认只输出一个中英双语版本。只有用户明确提出“中文版”“再出一版只有中文”或同义要求时，才额外或单独制作中文单语版。双语版的英文是字幕翻译，不扩写、不解释、不添加中文原话没有的观点。首次采用或改变样式时先做一份双语短样片；用户指定时长时按指定值执行，未指定时约 10 秒，确认前不渲染全片。

### 校对主稿不能直接烧录

`*_校对.srt` 用于确认“音频实际说了什么”，因此允许保留真实口语和较长的 ASR 条目。进入烧录前，必须结合原始 JSON 的词级起止时间另行生成展示字幕：

```text
校对 SRT 提供正确文字
+ 词级 JSON 提供每个词的真实时间
-> 跨越原 SRT 条目恢复连续词流
-> 去除无意义语气词、口吃和紧邻自我修正
-> 按完整意群、气口和屏幕可读长度重新分段
-> 生成中文字幕展示稿 / 中英双语展示稿
-> 烧录
```

拆分前必须先用原始词级时间戳建立完整的“讲话覆盖时间轴”。展示文字可以去掉语气词、口吃、重复起头并调整成更通顺的表达，但文字整理不得压缩它原本对应的讲话时间：字幕仍要从该原始口播意群开始时出现，并覆盖到该意群结束。连续讲话期间相邻字幕应无缝承接；只有真实无讲话或明确保护的纯画面演示区间才允许没有字幕。不得把一个十几秒 SRT 条目按字符比例平均分时，也不得只按“第一个保留词到最后一个保留词”截窄时码。默认中文每条约 `8-18` 个汉字、`1-4` 秒、单行显示；专名、英文词组、数字单位、固定搭配、修饰关系和动宾关系不得从中间拆开。30fps 成片最终时间边界按帧落地，画面有效精度约 `33.3ms`。

字幕层只清理不承担含义的口语残留。若完整语义内容在音频中重复数秒，应回到精剪删除对应音视频，不能只让字幕假装没有说过。

### 标点规则

- 中文展示字幕默认不显示逗号、句号、顿号等停顿标点，用分条切换表达停顿和层次。
- 英文展示字幕默认也不加句末句号和非必要逗号；句子过长时优先拆成下一条，而不是依靠标点塞进同一屏。
- 撇号、连字符、小数点、版本号和网址符号承载词义，不属于应删除的停顿标点。
- 只有无法继续自然拆分且不加标点会产生歧义时，才保留必要英文标点。

## 工作顺序

用户要求为剪辑成品制作字幕时，固定按以下顺序执行：

```text
从原始媒体重新识别 ASR / SRT
-> 保留一份不修改的新识别结果
-> 冻结精剪 EDL 并渲染无字幕成片
-> 复杂重排、大量短剪口、同步异常或映射冲突时，对成片完整重识别
-> 简单顺序剪辑使用 EDL 映射并重点抽查剪口
-> 生成疑难清单
-> 用户只纠正有问题的条目，未指出的按正确处理
-> 生成校对字幕 SRT
-> 抽查开头、中段、结尾和所有修改点
-> 烧录字幕版视频
```

在用户确认疑难清单前，不得烧录字幕，避免把错词固化进视频。用户没有指出的疑难项视为接受当前文字，但仍需修复明确的格式错误、非法时码和乱码。

用户明确要求“重新识别”或“跑完整流程”时，历史 SRT 只能作为比较材料，不得直接更名、映射或当作新识别结果。当前已验证的文字识别基准是剪映 SRT；未经当轮授权，不操作剪映或其他 GUI。

Apple Speech 已退出本项目工作流，不用于主识别、置信度比较、交叉校对或疑难筛选。正式无 GUI 新识别的技术默认是火山引擎大模型录音文件识别极速版，符合 2 小时和 100MB 限制的本地音频使用 Base64 直传；新识别结果未通过与剪映的人工样本比较前，不自动成为发布主稿。

火山引擎识别固定调用 `.agents/skills/volcengine-asr-srt/`，原始 API JSON 和生成的 SRT 必须同时保留。SRT 校验通过只代表格式和时间轴合法，不代表专名、数字和语义已经达到发布标准。

使用者必须自行配置并验证新版 API Key 或旧版鉴权信息。重新识别时读取项目外的私密配置，不在日志中回显凭据。默认只使用免费或预付额度，不得自动开通后付费；额度不足或要求进入计费时必须先停下并让用户决策。

云 ASR 的原始结果必须保持逐字可追溯。用于剪辑时默认关闭自动删除语气词、重复词或口水话的“语义顺滑”类功能；先获得尽量忠实的文字和时间戳，再由内容审稿与 EDL 决定删除什么。

## 疑难清单

疑难清单至少包含：

```text
成片时码
SRT 原文
候选文字
疑问原因
建议优先级
```

疑难清单还应给出 `当前推荐` 和 `判断依据`。如果候选来自上下文推断而不是可靠源材料，必须明确标记，不能把推论写成事实。

优先检查：人名、账号名、品牌名、软件名、模型名、英文缩写、专业术语、数字、金额、作品名、方言、上下文不通、明显同音错词，以及被剪辑边界截断的字幕。候选不能冒充确定答案；没有可靠候选时明确写“需回听”。

## 老胡默认字幕样式

除非用户针对某条作品另行指定，字幕版采用以下固定风格：

```text
画布：1920x1080，16:9
字体：思源黑体 / Source Han Sans CN
字重：默认按用户口述使用加粗；若需要复刻旧剪映工程，先确认 Regular 与 Heavy/Bold 的差异
字号：剪映默认 5 号；跨引擎实现时以手机端可读的最终视觉尺寸为准，不能把“5”直接当成 5px
文字：白色
描边：黑色，剪映参数 40
位置：X=0，Y=-793
阴影：黑色，不透明度 75%，模糊度 15%，距离 5，角度 -45 度
其他参数：沿用剪映默认值
```

画布与字幕位置必须先按源比例分流：

- 源视频已经是标准 16:9 时，画面等比铺满 `1920x1080`，字幕直接叠在画面下方安全区。白字、黑描边和黑阴影本身负责复杂背景上的可读性，不得为了给字幕腾位置而缩小画面、添加底部黑框或左右黑边。
- 源视频不是 16:9 时，才通过等比缩放完整保留内容，并利用多出来的画布余量安排字幕。黑色余量是非标准画幅适配的结果，不是所有字幕视频都必须具备的装饰。

剪映的字号、坐标、描边和阴影参数不是 ASS / FFmpeg 的同单位参数。使用其他渲染引擎时，必须先渲染代表性静帧，与用户提供的剪映截图进行视觉标定，再渲染整片；禁止机械把 `5`、`-793`、`40` 当成像素值。

## 非 16:9 素材

最终画布始终保持 16:9。源视频不是 16:9 时：

- 等比缩放，完整保留画面，不裁切软件界面或人物。
- 视频水平居中并贴齐画布顶边。
- 剩余区域使用纯黑背景，通常留在画面下方。
- 字幕固定放在成片底部安全区，可落在黑色留白区内。
- 即使字幕进入原视频区域，也必须保持白字、黑描边和黑阴影，确保复杂背景上可读。

## 输出和验证

默认保留三个职责不同的文件，不创建 `_v1`、`_最终版` 一类版本文件：

```text
新识别原始字幕：由原始媒体生成；高风险成片另保留成片新识别结果，不改文字
校对字幕：用户确认疑难项后的可发布 SRT
字幕版视频：烧录校对字幕后的最终视频
```

进入“字幕的烧录”流程时，默认只交付中英双语版。中文版是用户明确要求后才生成的可选交付，不是默认第二份文件。预览文件只用于样式验收，不计作正式版本。

烧录前后必须检查：字幕没有越过成片时长、时码单调、没有空字幕、中文断句自然、第二行不只剩一个字、最多两行、画面不被字幕遮住、手机缩小观看仍然清楚。还必须把展示 SRT 反向覆盖到原始词级 ASR：连续讲话中若存在任何“有人声词级时间、无展示字幕”区间，直接判定失败并修正时间映射。固定使用 `node workflows/laohu-video/模板/video-editing/validate-word-coverage.mjs --raw 成片.raw.json --srt 展示字幕.srt` 做全量覆盖校验，不能用静帧抽查代替。
