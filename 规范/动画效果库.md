# 动画效果库

本文件用于沉淀 Motion / MG 动画 / 数据可视化 / 图解包装中常见的动画效果名词、表现方式和适用场景。后续制作老胡口播视频时，优先从这里选择“能解释信息关系”的动效，而不是临时想一个装饰性动画。

## 1. 使用原则

动效选择顺序：

```text
口播语义 → 信息关系 → 动画类型 → 实现引擎 → 资产沉淀
```

判断标准：

- 这个动画是否帮助观众理解“谁和谁有什么关系”？
- 是否能随 ASR 节拍逐步出现、连接、强调和收束？
- 是否比静态卡片或文字列表更清楚？
- 是否适合后续抽象成 HyperFrames composition 或 Remotion template？

禁忌：

- 只因为“好看”就加复杂动画。
- 所有元素使用同一种淡入。
- 一开始展示整屏内容，后面长时间不变化。
- 用无意义粒子、旋转、闪烁、爆炸式转场抢口播注意力。

## 2. 入场 / 出现类动画

| 名词 | 表现效果 | 适用内容 | 推荐实现 |
| --- | --- | --- | --- |
| Fade In 淡入 | 元素透明度从 0 到 1 | 辅助文字、说明标签 | HyperFrames / Remotion |
| Fade + Slide 淡入位移 | 元素轻微上移、侧移后出现 | 标题、卡片、普通信息块 | HyperFrames |
| Scale In 缩放进入 | 元素从 0.94-0.98 放大到 1 | 重点卡、结论卡、徽章 | HyperFrames |
| Pop In 弹出 | 快速放大超过 1 再回落 | 少量关键标签、完成状态 | HyperFrames / Remotion |
| Mask Reveal 遮罩揭示 | 元素被矩形、圆形或路径遮罩逐步露出 | 标题、图片、图表、路线 | Remotion 优先 |
| Wipe Reveal 扫描揭示 | 扫描条划过后内容出现 | 章节切换、控制台刷新 | HyperFrames / Remotion |
| Draw On 绘制出现 | 线条、路径、轮廓逐步画出 | 流程线、曲线、箭头、关系图 | Remotion 优先 |
| Type On 打字出现 | 字符逐步出现 | 字段填写、搜索框、控制台文字 | Remotion / HyperFrames |
| Number Count 数字滚动 | 数字从 0 或旧值滚到新值 | 数据指标、进度、百分比 | Remotion 优先 |
| Stagger 分批错峰 | 多个元素按固定间隔依次出现 | 清单、步骤、路线卡、标签组 | HyperFrames / Remotion |

使用建议：普通信息进入用 `Fade + Slide` 就够；只在“字段填写、路径生成、图表增长”这类有语义的地方使用 `Type On / Draw On / Number Count`。

## 3. 离场 / 收束类动画

| 名词 | 表现效果 | 适用内容 | 推荐实现 |
| --- | --- | --- | --- |
| Fade Out 淡出 | 透明度降低 | 非重点辅助信息 | HyperFrames |
| Slide Out 滑出 | 元素向内容流动方向离开 | 旧卡片、旧状态 | HyperFrames |
| Collapse 折叠 | 多个元素收成一张结论卡 | 方法总结、流程收束 | Remotion 优先 |
| Zoom Out Overview 拉远总览 | 镜头拉远看到完整结构 | 流程地图、关系网络 | Remotion 优先 |
| Focus Lock 聚焦锁定 | 其他区域降透明，重点保留 | 结论、下一步、最终动作 | HyperFrames |
| Archive 归档飞入 | 文件、卡片飞入文件夹或资产库 | 产物留存、留痕记录 | Remotion 优先 |
| Checklist Complete 勾选完成 | 条目完成后形成完整清单 | 执行清单、验收标准 | HyperFrames / Remotion |

离场不要滥用。多场景切换时优先用全局转场遮罩覆盖旧画面，而不是让旧元素逐个退场。

## 4. 转场类动画

| 名词 | 表现效果 | 适用内容 | 推荐实现 |
| --- | --- | --- | --- |
| Hard Cut 硬切 | 直接切换 | 节奏非常快的短段落 | HyperFrames |
| Wipe 擦除转场 | 遮罩从一侧覆盖再露出新场景 | 常规章节切换 | HyperFrames |
| Push 推拉转场 | 旧画面被新画面横向或纵向推走 | 流程进入下一步 | HyperFrames |
| Zoom Transition 缩放转场 | 镜头推进到某个区域再切换 | 从总览进入局部细节 | Remotion 优先 |
| Match Cut 匹配剪辑 | 前后画面用相似形状或位置衔接 | 图形关系延续 | Remotion 优先 |
| Morph 形变转场 | 一个形状变成另一个形状 | 概念升级、状态转化 | Remotion 优先 |
| Glitch / Scan 扫描刷新 | 短暂数字化刷新 | 控制台、数据面板、系统感 | HyperFrames / Remotion |
| Page Flip 翻页 | 模拟翻页 | 一般不推荐，容易 PPT 感 | 慎用 |

本项目优先使用 `Wipe / Push / Zoom / Match Cut`，避免花哨翻页和大幅旋转。

## 5. 强调 / 提示类动画

| 名词 | 表现效果 | 适用内容 | 推荐实现 |
| --- | --- | --- | --- |
| Highlight Sweep 高亮扫过 | 高亮条从左到右扫过关键词 | 关键词、主结论 | HyperFrames |
| Pulse 呼吸脉冲 | 轻微亮度或缩放变化 | 当前节点、风险点、提醒 | HyperFrames |
| Glow 描边发光 | 描边或阴影变亮 | 选中路线、重点卡片 | HyperFrames |
| Dim Others 降权其他项 | 非当前内容降低透明度 | 对比、路线选择、长场景焦点转移 | HyperFrames |
| Badge Pop 徽章弹出 | 小标签弹出并停留 | “推荐”“风险”“下一步” | HyperFrames |
| Error Shake 错误抖动 | 错误项轻微左右抖动 | 错误路径、误区纠正 | 慎用 |
| Cross / Check 打叉勾选 | 错误项打叉，正确项勾选 | 正误对比、验收清单 | HyperFrames |
| Spotlight 聚光 | 光区或遮罩聚焦局部 | 案例拆解、截图标注 | Remotion 优先 |

强调动画必须短、准、少。一个画面同时只能有一个主强调。

## 6. MG 信息表达动画

| 模型名 | 表现方式 | 适用内容 | 模板方向 |
| --- | --- | --- | --- |
| 流程推进 Flow Progression | 节点出现 → 线条连接 → 当前节点点亮 → 产物出现 | 步骤、教程、生产链路 | `flow-map` |
| 关系生成 Relationship Build | 中心概念出现 → 分支生长 → 关联线补齐 | 因果、层级、依赖关系 | `relationship-map` |
| 正误对比 Wrong vs Right | 错误路径先出现并断裂 → 正确路径补全 | 误区纠正、方法替换 | `comparison` |
| 模板填写 Form Fill | 空模板出现 → 字段逐个填入 → 输出结果高亮 | 选题卡、发布包、复盘表 | `template-card` / Remotion |
| 数据切换 Metric Switch | 时间窗口点亮 → 指标卡切换 → 决策项锁定 | 2h/24h/72h 复盘 | `data-review` / Remotion |
| 风险闭环 Risk to Action | 风险出现 → 规避动作出现 → 留痕归档 | 合规、授权、素材来源 | `risk-dashboard` / Remotion |
| 漏斗转化 Funnel Build | 宽层到窄层逐级出现，当前层高亮 | 点击、停留、完播、互动 | `funnel-chart` |
| 矩阵选择 Matrix Selector | 维度坐标出现 → 方案卡进入 → 推荐路径高亮 | 路线选择、优先级判断 | `matrix-selector` / Remotion |
| 产物流转 Artifact Flow | 文件卡生成 → 箭头流转 → 下一轮优化 | 工作流产物、资产沉淀 | `artifact-flow` / Remotion |
| 视觉焦点转移 Focus Shift | 当前区域升亮，旧区域降权，焦点沿口播移动 | 长场景、中段变化 | HyperFrames |

## 7. 图表 / 数据可视化动画

| 名词 | 表现效果 | 适用内容 | 注意事项 |
| --- | --- | --- | --- |
| Line Draw 折线绘制 | 折线沿时间方向增长 | 趋势、增长、复盘 | 没有真实数据时只做趋势示意 |
| Area Fill 面积填充 | 折线下方面积逐渐填充 | 规模、增长趋势 | 避免像金融行情误导 |
| Bar Grow 柱状增长 | 柱子从基线增长 | 对比、排名、阶段量级 | 无数据时不要写具体数值 |
| Donut Progress 环形进度 | 圆环按百分比填充 | 完成度、占比 | 只用于真实或明确比例 |
| Funnel Narrow 漏斗收窄 | 从宽到窄逐层出现 | 转化链路 | 每层要写任务，不只写指标名 |
| Timeline Step 时间点推进 | 时间节点依次点亮 | 2h/24h/72h、版本迭代 | 适合 ASR 分段讲解 |
| Heatmap Reveal 热力显现 | 区域热度逐步出现 | 内容表现、点击区域 | 需要真实数据或明确示意边界 |
| Radar Sweep 雷达扫描 | 雷达轴线和扫描线出现 | 风险、维度评估 | 不要无限强循环 |
| Sankey / Flow 流向图 | 流量从左到右分叉或汇聚 | 来源、去向、分发 | 复杂时优先 Remotion |
| Scatter Cluster 散点聚类 | 散点出现后分组或圈选 | 分类、用户群、案例分布 | 避免信息太碎 |

数据动效必须说明“观察什么”和“因此做什么动作”，不能只展示漂亮曲线。

## 8. 镜头 / 空间类动画

| 名词 | 表现效果 | 适用内容 | 推荐实现 |
| --- | --- | --- | --- |
| Camera Push In 镜头推进 | 画面轻微放大进入细节 | 从总览到关键点 | Remotion 优先 |
| Camera Pull Out 镜头拉远 | 从局部拉到全局结构 | 总结、闭环 | Remotion 优先 |
| Pan 平移 | 镜头沿横向或纵向移动 | 长流程、宽图表 | Remotion |
| Parallax 视差 | 前后层移动速度不同 | 封面、开场、背景氛围 | Remotion / HyperFrames |
| Depth Cards 层叠卡片 | 卡片有前后深度和轻微位移 | 多方案、多步骤 | Remotion |
| 2.5D Tilt 轻微倾斜 | 卡片或面板有透视倾斜 | 控制台、产品感画面 | 慎用 |
| Picture-in-Picture 画中画 | 人像 / 案例 / 图解并置 | 讲解 + 示例 | HyperFrames |

镜头运动适合提升精品感，但不应让文字可读性下降。

## 10. 常见自媒体 MG 包装元素

| 元素名 | 表现效果 | 适用内容 | 注意事项 |
| --- | --- | --- | --- |
| Lower Third 下三分之一条 | 人像下方出现身份、主题、关键词 | 口播人像包装 | 不遮挡字幕 |
| Callout 标注框 | 箭头或线条指向画面局部 | 案例截图、PPT 截图 | 每个标注必须有解释任务 |
| Tip Badge 提示圆牌 | 圆形或胶囊标签弹出 | 小技巧、提醒、风险 | 不要太多 |
| Floating Card 悬浮卡 | 信息卡悬浮在人物旁边 | 重点概念、操作步骤 | 注意人物脸部避让 |
| Progress Strip 进度条 | 顶部或底部显示章节位置 | 长视频定位 | 不要抢主画面 |
| Chapter Bumper 章节包装 | 章节号 + 本段问题 + 进度 | 段落切换 | 3 秒内完成 |
| Cursor / Pointer 指针 | 模拟点击、选择、拖动 | 软件教程、选择动作 | 路径要服务口播 |
| Sticker Label 贴纸标签 | 短词标签强调情绪或状态 | 自媒体感包装 | 控制数量和色彩 |
| Screenshot Annotation 截图标注 | 截图上画框、箭头、放大镜 | 案例拆解 | 保证标注可读 |

## 11. 本项目推荐的动画模板分级

### A 级：长期高复用

- `flow-map`：流程推进。
- `template-card`：模板填写。
- `comparison`：正误对比。
- `checklist`：执行清单。
- `data-review`：复盘面板。
- `risk-dashboard`：风险到动作。
- `transition-wipe`：场景转场遮罩。
- `arrow-system`：箭头与关系连接。

### B 级：适合 Remotion 精修

- `route-matrix` / `matrix-selector`：路线选择矩阵。
- `topic-form`：可填写选题卡。
- `media-cards` / `funnel-chart`：传播漏斗和媒体形式卡。
- `review-dashboard`：2h / 24h / 72h 数据面板。
- `growth-curve`：阶梯同步增长曲线。
- `artifact-flow`：产物流转。
- `risk-radar`：风险雷达和闭环。

### C 级：谨慎使用

- 粒子爆炸、强 Glitch、大幅 3D 翻转、复杂 Orbit、频繁弹跳、长时间闪烁。

## 12. 从动画名词到制作指令的写法

不要写：

```text
这里做酷一点的动画。
```

推荐写：

```text
使用 Matrix Selector：先出现两条判断维度，再让 6 张路线卡错峰进入；口播讲到“先选 1 主 1 辅”时，其他路线降权，主辅路线描边高亮，底部出现决策结论。
```

推荐字段：

```text
动画模型：
触发口播 / ASR 时间：
入场方式：
中段状态变化：
强调方式：
收束方式：
推荐引擎：HyperFrames / Remotion / 双引擎
输出资产：html composition / webm / png 序列 / 静帧
复用价值：一次性 / 可复用模板
```
