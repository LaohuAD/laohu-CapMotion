# 老胡 Remotion 动画导演

**口播讲路，动画显理。** 先保护观众要理解的关系，再决定形式；能用一次清楚的变化说明，就不平均铺满特效。画面必须补充口播的结构、证据或操作，不能只把原话换成大字。

**先看关系，再看效果。** 知识解释先回答观众原来误解什么、看完以后多懂了哪一层关系，再决定怎么动。形式、组件和特效服务这次变化；展示、开场与情绪任务按各自的观看目标判断。

注意力建立、章节开场、情绪与作品展示也可以是正当任务，不必伪装成知识流程图。新奇来自贴合当前材料的揭示、运动和结果，不来自固定皮肤或特效数量。

## 从什么输入开始

本 Skill 同时负责创意转译与实现。先判定输入所处阶段，不要求用户或老胡文稿先替动画导演完成全部设计：

- **整片 / 章节画面策划**：用户要求动画规划或后期总装时，先按 [动画导演转译规范](../../../workflows/laohu-video/规范/动画导演转译规范.md) 的“从成片内容划分动画单元”检查请求范围内的连续讲述及真实底画。主动判断哪里需要动画、哪几段共同完成一个解释、何时进入和退出、要哪些材料、局部还是全幅覆盖；不要只加工制作脚本已经标注的动画点。具体指定一段时只检查该段与必要前后文，不扩大到整片重做。
- **灵感 / 粗略建议**：读对应口播、上下文、素材和参考，按 [动画导演转译规范](../../../workflows/laohu-video/规范/动画导演转译规范.md) 补成动画设计。先确定看什么、怎么变化、最后留下什么，再选实现方式。缺动作、镜头和节奏属于本 Skill 要完成的设计工作；缺事实、原始素材或改变内容承诺的决定才需要补充。
- **已有明确设计**：保持用户锁定的对象、顺序、主张、最终状态和参考职责，补足可执行细节；不另起炉灶重设方向。
- **正式制作**：将设计落入当前任务已有 `narrative / annotation / knowledgeVisual / overlayContinuity`，通过下述输入闸门，再用官方知识写代码、预览、验证并回填 Cap。技术知识不是另一个会自动接单的生成服务，执行 Agent 负责读文档、实现和渲染。

只有脚本预计时间或没有时间时也能先设计，明确标为“设计草案 / 相对节拍待对齐”；不能伪造冻结 T2、ASR、已验收素材或用户批准。没有口播的独立创意请求可交付相对秒数的设计稿；本项目正式生产链仍按已验证接口执行，不用假合同强行过闸。

完整后期的转译结果写进同一份预剪辑审稿主文档，先与剪辑、字幕一起讨论和修改；用户对当前整份方案批准后才实现动画、渲染与写入 Cap。按转译规范的“与虚拟剪辑一起审稿”处理图片反馈、批准范围和修订失效。已有作品 `控制文档.md` 保留定位和锁定决定，不复制逐拍方案；独立创意或已授权局部返工仍可直接写对应控制场景。技术 props、Composition 和资产路径放制作记录。不要另建竞争权威的“最终提示词”，也不把文字设计字段擅自添加到运行时 schema。

前置策划必须先留下“讲解单元与画面安排”：对应保留片段/词流、语义目标、是否采用动画及理由、内容范围、覆盖起止与边界理由、底画职责、所需图片/截图/文字及准备状态。主责在本 Skill；后期总装提供剪辑权威并回收计划。组合动画只组合视觉解释，不重排或拼改声音。脚本中的粗建议是候选；用户明确锁定的场景及材料仍需继承，改变已锁定取舍应说明并确认。

完整后期的主审稿默认采用 HTML 时间轴：按 `workflows/laohu-video/模板/口播精剪审稿模板.md` 将本 Skill 的方案写入同一审稿 JSON 的 `visuals`，引用真实 `segmentIds`；图片逐张注明用途并提供实际预览或缺口。后期统一生成左右对应的 HTML，导演不另写竞争主稿或自行根据页面高度推算时码。用户网页导出的意见要核对修订后合入数据，再生成新视图。

## 读取材料

先读当前作品控制文档、制作脚本、虚拟剪辑后的连续文字与保留片段列表、词级时间及源到成片映射、已有成片 ASR、请求范围的前后文和素材索引；结合源媒体/工作工程查看真实底画。设计时先读上述转译规范，确定画面意图后再读：

- `workflows/laohu-video/规范/画面表达规则.md`
- `workflows/laohu-video/规范/组件设计方法论.md`
- `workflows/laohu-video/规范/组件规则.md`
- 决定复用组件后才读对应的 `workflows/laohu-video/模板/components/` 说明

其他规范不得全量默认读取。必须按 [动画知识路由与激活](references/动画知识路由与激活.md) 的触发条件选择，并留下激活回执。实现知识以 `remotion-best-practices` 为唯一外部入口，再由它路由内部 Markup、Interactivity、Rendering 或 Captions 页面；不把这些外部知识当作第二套项目审美规则。

## 正式制作输入闸门

只有正式制作才接受 `T2` 冻结成片时间段。通用观众变化、媒介理由和前后承接只从任务 `narrative` 读取；`REMOTION.annotation` 只负责动画独有的解释对象、对象关系、进入方式、变化过程、收束画面、材料和验收。不得在两处复制同一判断形成双重权威。只写“这里做动画”时先进入转译，不直接当成坏输入退给用户；仍不足以执行时保留 `REMOTION_ANNOTATION_INCOMPLETE`，说明缺的是哪项事实或尚未完成的设计，禁止拿空批注直接制作。

当 `narrative.purpose=UNDERSTAND` 时，还必须具备 `KnowledgeVisualContract`：已有合同从上游继承；仅有粗建议时由本 Skill 基于已确定主张完成视觉设计，再交后期负责人写入同一任务。它保存本段主张、知识类型、语义对象、初态、作用、状态变化、结果、观众应得出的推论、口播—画面语义锚点、少量大标签、摄影机 / 视窗职责及静音与声画同步验收。`carrierDecision` 必须是 `REMOTION_OVERLAY`。合同缺失、对象只是题材图标、没有状态变化或没有语义锚点时，返回 `KNOWLEDGE_VISUAL_CONTRACT_INCOMPLETE`；`TRANSITION`等不承担知识证明的动画不强行虚构该合同。

每个正式 Remotion 任务还必须具备 `OverlayContinuityContract`，由本 Skill 与后期负责人依据真实底画补齐。它负责同一语义信息层跨真人、录屏、数字人、证据和 `AI_VIDEO_FULL` 的状态连续：`groupId / order` 标识同一连续组，`stateBefore → stateUpdate → stateAfter` 形成状态机，后一段必须接住前一段结果。底画换了不等于语义重置；章节进度、证据标签或结论尚未完成时，应由同一组件家族在新底画上继续，而不是重新入场、换皮或归零。

当 `hostCarrier=AI_VIDEO_FULL` 时，还必须取得 `hostCompatibility`：视觉锚点、稳定负空间、亮度分布、运动负荷、禁止叠加窗口、注意力交接和真实像素复核状态。上游建议只能作为预判；最终位置和对比方式由本 Skill 对用户手动生成的真实视频合成复核后决定。缺失时返回 `AI_HOST_COMPATIBILITY_INCOMPLETE`。

## 必要章法

整片/章节请求先完成讲解单元组合与画面安排，选中的动画单元再逐项执行下列步骤。没有动画也应有明确的原画面/证据安排；不以动画数量或覆盖率充当完成标准。

1. 先写清本段的观众变化：知识段从疑问走到可复述的理解，展示/开场/情绪段写被建立的注意力、主角或感受。结合材料完成转译规范中的画面理解、动作/镜头/声音节拍和最终状态；只有内容目的本身缺失或冲突时才返回上游，不先选组件。
2. 把完整语义段拆成必要叙事节拍：承接、建立对象、作用触发、状态变化、结果收束、可读停留。知识段以 `semanticAnchors.spokenCue → visualEvent` 为节拍权威，通常是 3–7 个，但简单关系不为凑数扩写，复杂关系也不为守数字硬压。
3. 给上屏内容标 `asr / context / source-doc / editorial / illustrative`；`source-doc` 必须有引用。
4. 判断 `communicationGoal / emotionalTone / informationShape / motionIntensity`。
5. 先审设计的实际表达，再按信息形状、沟通目标、容量、情绪、成熟度选择复用、组合或作品专属 Composition；组件目录不是创作上限。关键位置存在真实取舍时，比较真正不同的表达方向；记录主胜负手、保留理由、否决理由和可观察增益，不把换颜色、换词序当作候选。
6. 再决定呈现方式。以下字段用于现有公共组件，作品专属 Composition 以自己的受校验 props 承接相同视觉职责。需要保留真人、录屏或证据素材时，优先使用 `presentation=overlay`、`renderMode=asset`，根据人脸、手势和底部字幕选择 `placement=left/right`；只有章节定场或必须独立理解的完整图解使用 `stage`。需要跨载体维持章节、证据、标签、数值或桥接状态时，优先调用可复用的 `EditorialOverlayShell`，按职责选择 `progress-rail / evidence-dock / label-stack / value-callout / bridge`，不为每条视频另造一次性组件。叠层不能和底画已有同类图解重复。
7. 再决定字体职务。知识段先按 `labelPlan` 把少量中文大标签就近绑定到对象，标签只负责身份、动作、结果或边界，不用密集小字、随机英文或乱码填充信息量。中文主标题、英文展示字、数字、英文眉题和中文正文不能共用一套字号/字重/字距；需要两行不同语义色时显式写 `titleLines`，不让组件按字数猜断行。参考成片没有字体源文件时只能选视觉近似，并在验收里保留这个事实边界。
8. 用 `accentRole` 表达语义：信息/过程用 `info`，成立/增长用 `success`，权威/价值用 `warning`，否决/风险用 `danger`，技术过程用 `technical`。不能为刷新画面随机换色。
9. 复用组件时生成通过 Zod 的 `ComponentConfig`；作品专属 Composition 使用自己的 props schema 并注册到共享 workspace，不能谎填一个并不存在的家族。绝对时码只放 `sourceTimeRange`，动画内部使用相对帧。把每个语义锚点映射为对应 `items.revealAtFrame`、状态替换或结果锁定帧，以完整语义点而不是平均间隔或逐词触发；未指定时保留组件自动错峰。已经进入的对象默认持续留到本段关系收束，除非脚本明确要求它被替换或否决。知识段的视窗移动用于显露层级、跟随作用路径、从输入交接到结果或完成焦点转移；若没有学习增益则固定视窗。展示与情绪段按观看目标决定运镜，仍须保护材料和焦点。
10. 先审宿主画面再决定是否落动画：记录该时间段是否正在拖拽、点击、输入、播放证据或连续展示结果。真实操作已经承担解释时，拒绝用全幅知识动画覆盖；要么延后到稳定口播段，要么只做不遮挡操作对象的指示叠层。批准为全幅知识动画后，老胡教学视频默认使用 `FULL_SCRIM` 压暗完整宿主画面，让观众仍看得到原画上下文但把焦点交给关系动画；局部箭头、框选和操作标注仍按最低充分原则选择 `NONE / LOCAL_BACKPLATE / REGIONAL_SCRIM`。预览承接帧、变化中段、收束帧、最终停留和手机缩略图，并把透明叠层合成到真实底画抽查人脸、手势、证据、字幕和视觉锚点。知识段同时执行 `silentTest` 与 `audioSyncTest`：静音后仍能看出核心对象、作用、状态变化和结果；恢复口播后，画面变化必须在对应语义触发处发生，不抢跑也不滞后。先过可用底线，再判断焦点、节奏、信息增益和整片连续性。
11. 用 revision-safe `cap motion` 命令写入上层 Motion 轨；底层视频、录屏和主音频不变。

## 技法必须回答

每个被选择的动画技法都要记录：作用对象、要改变的理解/证据/情绪/行动、此处使用理由、所需材料、怎样进入/变化/收束、过量风险。例如“路径汇流”适合解释多来源进入一个决策，不适合仅为一句口号增加运动。

## 法度与审美验收

- 程序动画唯一引擎是 Remotion。输出仅 `standalone / asset / both`，接入方式是 Cap Motion 上层轨。
- 可复用编辑叠层以 `EditorialOverlayShell` 为统一壳；新增常用模式必须同步 schema、注册表、示例、组件说明和测试，避免同一种进度、证据或桥接信息反复翻新。
- 公共组件配置或作品 Composition 的 props 必须通过对应 Zod、TypeScript 和必要行为验证；事实、数字和案例必须可追溯。
- 视觉组件默认静音；声音设计单独记录触发、素材、口播避让与交付状态。只有明确交付独立有声片段时才内嵌音频。Cap 音效须验证独立音轨/混音链，不能把画面导入成功说成音效已听见。
- 检查完整 1920×1080 帧和 390×219 缩略图：空白、遮挡、中文断行、焦点、关系误导和停留时间。
- 机械检查不能证明画面高级。还要观看判断动画是否抢口播、节奏是否拖、前后镜是否连续、收束画面是否让观众看懂。
- 如果仍有一个已知、可执行且会明显提高主胜负手的改法，不能因为 schema、测试和渲染已经通过就结束。

## 能力缺口

没有合适公共 schema 时，说明观众收益、缺少输入和兼容风险，再选择当前适配、组合、注册作品专属 Composition、升级公共组件或拒绝。专属 Composition 仍使用同一 Remotion 引擎、共享 workspace、可校验 props 和 Cap definition，不必先成为长期家族。公共升级必须同步 schema、注册表、示例和测试；不允许未登记、无源码回溯的临时入口。
