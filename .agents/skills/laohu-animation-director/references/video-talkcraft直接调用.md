# video-talkcraft 直接调用说明

## 用途与路由边界

只有当动画导演已把当前讲解单元选定由 TalkCraft 负责时，才直接调用已安装的上游 Skill `.agents/skills/video-talkcraft/SKILL.md` 及其原始卡片、TSX、motion-systems 和脚本。这里仅限定它在老胡后期链里的工作阶段与输入，不复制或改写上游技法。

- 本地动画导演掌握剪后语义、T2 时间、底画、用户审批、冻结和 Cap 总装。
- 上游负责其制作能力：②-1 语义标注、必要的素材策划、原卡选择、SHOTBOOK、Remotion 制作与适用质检。
- 需要整体审稿的策划候选回到现有联合审稿；SHOTBOOK 是制作工作单，不是第二审稿稿源，也不能批准自己。
- 规划可在虚拟精剪成立后进行；正式制作仍须适用的现有授权和冻结 T2。已授权局部返工只处理获准单元，不扩成整片重审。
- 无口播独立动画继续使用本地 `contentMode=standalone` 与 `timingMode=relative` 入口；本路由不替换它。
- 纯剪辑、SRT 校正、字幕排版，以及 Cap 原生文字/高亮已足够的任务不调用本 Skill。

上游没有 animation-only flag。每次调用都明确“阶段限定调用”，不伪造 CLI/API 参数。只执行本任务需要的原始步骤，不延伸为整片旁白剪辑、字幕重做或全套新片工作流。

## 阶段、输入和输出

| 阶段 | 输入与动作 | 输出及闸门 |
| --- | --- | --- |
| A. 动画策划 | 当前虚拟精剪审稿、校正后的 T2 展示字幕、当前虚拟映射及其冻结状态、原录音/源定位线索、请求范围真实底画。直接调用上游②-1语义标注、必要素材策划、taxonomy/card_match 与 SHOTBOOK；只读所选原卡。 | 形成卡片/语义/材料候选，合并到同一份审稿 JSON 的现有画面单元；此阶段不要求映射已冻结，不改批准、不写工程、不渲染。 |
| B. 正式制作 | 适用范围的方案已获现有授权，任务包的 T2 与映射已冻结；输入只含获准单元、准确 T2 范围、真实底画与获准材料。直接调用上游原卡 TSX、motion-systems、Remotion 和适用的 card_lint/beat_lint。 | 输出与主音频分离的静音 Remotion 资产及检查回执，交回现有 Cap Motion/总装流程。不得改变剪辑、字幕、批准范围或主音频。 |

需要整体审稿的任务，策划候选须回到当前唯一审稿并按原批准规则确认；用户的“制作”授权不替代冻结 T2。已授权局部返工沿用其单元范围，不因此重开整片。

## 最小输入契约

| 数据 | 用途与真源 |
| --- | --- |
| 校正后的 T2 字幕 | 画面要表达的显示文字与语义提示。保留目标起止时间和字幕 ID。它不是新的原始 ASR。 |
| 原录音、原 ASR 词级时码 | 原录音是发声内容依据；ASR 词级时码是源定位线索，需与录音/已核验材料相符，不把识别文字当绝对发声真值。 |
| 当前虚拟映射；正式制作时的冻结 EDL、源到成片映射 | 策划用当前映射判断候选与状态；正式制作必须用与任务修订一致的冻结映射追溯源事件到目标 T2。 |
| 底画/截图与材料索引 | 判断卡片是全幅资产还是可叠层；每张材料都须有来源、用途和批准范围。 |
| 当前审稿与批准/冻结回执 | 唯一的画面决定、范围与制作授权。 |

原录音、ASR 转写、校正显示文字、目标 T2 时间和 ASR 源时间是不同证据，必须并存并保留来源。不得用修改后的校正字幕覆盖 `timestamps.json` 的原词文本来通过上游的精确文本校验。若经录音确认只是同音字校正且对应同一真实发音，可保留那个原词的时间定位；改写、合并或拆分文本不能因此伪造成逐字对齐。

若校正字幕改字、合句或拆句，不能把句级改字当作逐字发声证据。只有项目映射确实指向真实源词，才可继承那个词的源时码。没有可追溯的目标字级锚点时，只做候选策划或已核实边界上的安排，不声称上游字锚检查通过；不按字数平均、不凭感觉补词时码。上游 `make_timing.py` 只接收由真实兼容时间戳派生的数据，它生成的 timing 是派生物，不是 Cap 自动导入。当前没有 Cap 自动导入适配器。

如果某个上游脚本要求的数据结构不存在或不能从原始证据精确构造，停止该脚本和对应的通过声明；保留上游原版能力用于其它可执行步骤，并报告具体缺口。不得为凑齐 JSON 字段伪造 ASR、T2 词位或 lint 成功。

## 可直接发送给 video-talkcraft 的阶段限定调用文本

复制后填入路径和阶段；让它直接读取上游原文，不要要求它“参考后自行实现一套”：

> 当前讲解单元已被本地动画导演选定由 TalkCraft 负责。请直接执行本项目已安装的原版 `.agents/skills/video-talkcraft/SKILL.md`，并遵循其 taxonomy、semantic_annotate/card_match、所选原卡说明与原 TSX、motion-systems 和适用的 card_lint/beat_lint。当前阶段是【策划 / 正式制作】；范围是【作品、视觉单元、T2 范围】。输入：校正后的展示字幕【路径】、原录音及 ASR 源定位线索【路径】、当前虚拟映射【策划】或已冻结的 EDL/源到成片映射【正式制作】、适用批准与冻结状态【路径】、真实底画与材料【路径】。校正字幕只作显示语义，不覆盖原始发声或时码。不要执行文案改写、voice_trim、timestamps_cpu、新 ASR、TTS、剪辑、改音频或字幕重做；不运行 runtime --upgrade、npm install，不改依赖锁文件。策划阶段只返回原卡候选、语义/材料判断和 SHOTBOOK 候选，供本项目合入唯一审稿；不写代码、不渲染。制作阶段仅在适用授权和 T2 冻结已核实后实现获准单元，保留原卡运动，只作上游规定的 props/素材/风格配置及必要宿主适配，输出静音资产给现有 Cap Motion 流程。逐项说明哪些上游检查实际运行、哪些整片流程不适用或因数据缺口未运行；不得把局部检查说成全量 preflight 通过。

## Cap 接回与质检

- 原卡保真优先。只使用上游定义的 props、素材/风格配置和必要宿主适配；不得另写同名动画来替代卡片运动。
- 原卡不保证透明。例如 `source-converge.tsx` 第 128 行画了白底。检查实际 TSX、实际合成预览、画幅、帧率、时长和 alpha 后，按已批准画面职责接全幅资产，或使用允许的背景/宿主适配；不得把“复制 TSX”说成天然透明叠层。
- 接回现有 Remotion 静音资产/Cap Motion 上层轨。音效事件单独记入现有清单；不能嵌入、替换或重混主音频。
- 选卡以原版 taxonomy/card_match 和实际卡说明为准。本地导演提供语义、时间、底画及批准边界，不预先指定一张卡，也不把候选当批准。
- 只报告本范围实际适用并执行的 card_lint、beat_lint、媒体规格和真实画面检查。未执行的上游全片 B-roll 配比、人物角标、字幕重做、Workbench、Manim 等，不纳入本项目任务，也不能虚报全量 preflight。
- 共享 workspace 依赖保持原样；不执行上游 runtime 升级命令、不安装依赖、不改锁文件。
