# Source Audio Tracks and Recording Mic Mute Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Let users expand recording-owned microphone and system audio from Video into non-movable child rows, remove source audio without changing time, and mute the microphone during either Studio or Instant recording.

**Architecture:** Store source-audio presentation and edit state under the existing project audio configuration, keyed by original recording clip and source time. Video remains the only movable timeline structure; child rows derive their positions from Video and edit source-specific mute ranges and cut points. The Rust audio renderer applies the same source-time mute ranges in preview and export, while the existing recording-scoped microphone lock is exposed to Studio as well as Instant mode.

**Tech Stack:** Rust (`cap-project`, `cap-editor`, `cap-recording`, `cap-desktop`), TypeScript/SolidJS, Vitest, Cargo tests, Tauri/Specta generated bindings.

---

## File Structure

- `crates/project/src/configuration.rs` owns persisted source-audio configuration, normalization, and source-time queries.
- `crates/editor/src/audio.rs` applies source-specific audibility while mixing microphone and system audio for preview/export.
- `crates/editor/src/segments.rs` tags decoded recording tracks as microphone or system audio.
- `apps/desktop/src/routes/editor/source-audio.ts` provides pure child-span derivation and edit helpers for the frontend.
- `apps/desktop/src/routes/editor/source-audio.test.ts` verifies child-span and non-ripple edit behavior.
- `apps/desktop/src/routes/editor/context.ts` exposes source-audio selection and project actions.
- `apps/desktop/src/routes/editor/Timeline/SourceAudioTrack.tsx` renders a non-draggable child row.
- `apps/desktop/src/routes/editor/Timeline/ClipTrack.tsx` omits an expanded source from the Video waveform.
- `apps/desktop/src/routes/editor/Timeline/index.tsx` wires Add Track, collapse, shortcuts, deletion, and row ordering.
- `apps/desktop/src/routes/editor/Timeline/TrackManager.tsx` describes the two conditional source-audio entries.
- `apps/desktop/src/routes/recording-mic-mute.ts` provides a pure eligibility rule shared by UI and tests.
- `apps/desktop/src/routes/recording-mic-mute.test.ts` covers Studio/Instant eligibility and disconnected states.
- `apps/desktop/src/routes/in-progress-recording.tsx` uses the shared eligibility rule and existing optimistic mutation.
- `apps/desktop/src-tauri/src/recording.rs` permits the existing recording-scoped mute lock in Studio.
- `apps/desktop/src/i18n-literals.ts` contains the new user-facing English/Chinese strings.
- `apps/desktop/src/utils/tauri.ts` and `apps/src/utils/tauri.ts` are generated by the existing Specta/Tauri preparation flow and must not be edited manually.
