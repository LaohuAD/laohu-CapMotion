# 字幕样式、应用内大屏预览与 Motion 画布编辑设计

日期：2026-08-31  
状态：设计已确认，实施计划已完成  
范围：Cap 桌面端编辑器；不改变时间轴剪辑语义，不引入新的动画引擎

## 1. 结果目标

本轮不是单纯给界面补几个控件，而是让三类操作形成真实闭环：

1. 字幕面板设置的字体、字重、字间距、描边和阴影，在预览与最终导出中一致生效。
2. 用户无需导出或打开第二个窗口，就能在同一个编辑器里放大预览、拖动进度、播放和暂停。
3. Remotion 动画进入 Cap 后，用户可直接在预览画布里调整位置和显示大小；调整只改 Cap 合成参数，不重新渲染动画。

核心取舍：交互控件必须落到真实工程字段和最终渲染链，不能只做前端视觉模拟。

## 2. 已确认的现状与问题根因

### 2.1 字幕

- 当前 `Font Weight` 修改的是数值字重，但字幕 GPU 渲染器只认识三种抽象字体族。任意字体名都会回落到系统无衬线字体，因此字重变化时可能触发不同的系统回退字形，看起来像换了字体。
- 工程已有 `outline` 与 `outlineColor`，但描边宽度写死；没有字间距字段，也没有完整阴影字段。
- 字幕面板仍有未进入统一本地化映射的英文分组名、选项名和说明。
- 前端字幕测量与 GPU 最终渲染各有一套字体映射，存在预览和导出不一致的风险。

### 2.2 预览播放器

- 当前播放器已经有播放、暂停、跳到开头和结尾，但没有可拖动的播放进度条，也没有应用内大屏模式。
- 预览依赖一个已初始化的 GPU canvas。若为了放大重新创建第二个 canvas，会增加重建解码器、黑帧和缓存失效风险。

### 2.3 Remotion 动画画布编辑

- Motion 工程字段已经包含 `x / y / scaleX / scaleY / rotation`，右侧参数面板也能修改。
- 最终渲染把 `x / y` 解释为相对输出画布中心的像素偏移，把缩放解释为相对整张输出画布的比例。
- 预览画布当前没有 Motion 的可交互选框，因此用户只能使用滑块，无法像编辑普通画面元素一样直接拖动。

## 3. 方案选择

### 3.1 字幕采用端到端样式链

拒绝只给 DOM 预览增加 CSS。新增字幕设置必须同时进入：

```text
字幕面板 → 工程 schema → 保存/加载 → 前端测量 → GPU 预览 → 最终导出
```

任何一段缺失，都视为功能未完成。

### 3.2 预览采用同一 canvas 的应用内大屏模式

点击放大按钮后，不创建第二个播放器窗口，也不重新挂载 canvas；只把现有播放器容器切换成应用内的固定大屏层。这样可继续复用已经初始化的 GPU、解码器和播放状态。

### 3.3 动画采用 Cap 合成变换，不回写 Remotion 源码

拖动和缩放只修改 Motion segment 的 transform。动画源视频、Remotion 配置、artifact 状态和缓存均保持不变。只有动画内容本身改变时才需要重新运行 Remotion。

## 4. 字幕详细设计

### 4.1 字体与字重

字体列表分为两部分：

- 随应用提供：思源黑体、思源宋体、霞鹜文楷。
- 本机字体：复用现有系统字体枚举能力，允许用户选择已安装字体。

随应用字体使用可商用的开源授权版本，并随安装包携带对应许可证。大体积字体二进制不直接塞入普通源码目录；用带固定版本与校验值的资源清单在构建阶段取得，再作为应用资源打包，以避免 Git 仓库无谓膨胀并保证构建可复现。

字体族和字重必须分离：

- 改变字重时不得改变已选字体族。
- 字体缺少指定字重时，在同一字体族内选最接近的真实字重。
- 找不到整套字体族时，才使用明确记录的回退字体，并在界面中显示可理解的回退状态。

### 4.2 新增和完善的工程字段

在 Caption settings 中新增可向后兼容的字段，旧工程通过默认值继续加载：

```text
letterSpacing: number
outlineWidth: number
shadow: boolean
shadowColor: string
shadowOpacity: number
shadowBlur: number
shadowDistance: number
shadowAngle: number
```

保留已有 `outline`、`outlineColor` 和 `fontWeight`。默认样式尽量维持旧工程现有视觉，不因升级自动给旧字幕加重阴影或改变字距。

### 4.3 界面结构

字幕面板按真实职责分组：

- 字体：字体、字重、字号、字间距、斜体、大小写。
- 填充：文字颜色、高亮颜色与现有活动词设置。
- 描边：开关、颜色、粗细。
- 阴影：开关、颜色、不透明度、模糊度、距离、角度。
- 背景、位置、动画、导出：保留现有能力并完成本地化。

中文模式下，分组标题、按钮、选项、滑块说明、空状态和工具提示均显示中文；代码、字体内部名称、路径和工程枚举不翻译。

### 4.4 渲染一致性

- GPU 字幕渲染器加载随应用字体与系统字体的真实字形数据。
- 字间距参与实际字形布局，而不是只改变测量框。
- 描边宽度参与最终渲染，不再使用固定常量。
- 阴影按角度和距离计算偏移，按不透明度与模糊度渲染；预览和导出共用同一算法。
- 选择框和文本测量必须使用与渲染器一致的字体族、字重和字间距，避免拖动边界与屏幕文字错位。

## 5. 应用内大屏预览设计

### 5.1 进入与退出

- 播放器右上角新增“放大预览”按钮。
- 点击后，现有播放器容器进入覆盖编辑区的应用内大屏层，不新建系统窗口。
- `Esc` 退出大屏；再次点击按钮也可退出。
- 大屏不抢占 macOS 系统全屏空间，不触发 GPU canvas 重新初始化。

### 5.2 播放控制

普通模式和大屏模式共用同一套播放状态与控制逻辑：

- 播放/暂停。
- 当前时间与总时长。
- 可拖动进度条；拖动时连续更新预览，松手后停在准确时间。
- 跳到开头和结尾的现有能力继续保留。
- 点击画布空白区域切换播放/暂停。
- 当指针位于字幕、文字、遮罩或 Motion 的编辑框及控制点上时，点击只执行编辑，不触发播放切换。
- 空格键继续控制播放/暂停。

### 5.3 性能原则

- 大屏前后保持同一个 canvas DOM 节点。
- 不因切换大屏清空解码缓存，不复制播放循环，不额外启动渲染任务。
- 进度拖动复用现有 seek 能力，并对高频指针事件做帧级合并，避免每个像素移动都排队解码。

## 6. Remotion 动画预览画布编辑设计

### 6.1 选择规则

- 播放头处于某个 Motion segment 的时间范围内时，该动画可在画布中选择。
- 未预先选择时，点击重叠区域选择当前可见且 `zIndex` 最高的动画。
- 若要调整被遮住的低层动画，用户先在时间轴选择对应 segment，画布即显示该动画的编辑框。
- artifact 缺失或处于失败状态时，不提供虚假的编辑框；显示明确状态并保留时间轴数据。

### 6.2 直接操作

- 拖动画面主体：修改 `transform.x / transform.y`。
- 拖四角控制点：默认等比例修改 `scaleX / scaleY`。
- 拖动时显示画布中心与边缘吸附线；接近目标时吸附，继续拖动可越过。
- 第一阶段不增加画布旋转手柄；旋转仍通过右侧参数面板修改。
- 画布调整不改变 segment 的开始时间、结束时间、轨道、角色或层级。

### 6.3 坐标和历史记录

- DOM 选框从输出画布像素坐标换算到当前预览缩放后的 CSS 坐标。
- 写回时再从 CSS 坐标换算为输出画布像素偏移，确保不同预览尺寸得到相同导出位置。
- 一次完整的按下—拖动—松开只形成一个撤销历史节点，不能每移动一个像素就产生一条历史记录。
- transform 改动不得把 Remotion artifact 标成 `stale`，因为素材内容没有改变。

## 7. 兼容、错误和非目标

### 7.1 兼容

- 新字幕字段均有 serde / TypeScript 默认值，旧 `.cap` 工程可直接打开。
- 旧字幕在未手动调整时尽可能保持原有画面。
- 现有 Motion 时间轴拖动、时长缩放、互斥规则和 Remotion artifact 缓存保持不变。

### 7.2 错误处理

- 随应用字体资源缺失或校验失败时，构建明确失败，不能静默产出缺字体的安装包。
- 用户选择的系统字体后来被卸载时，界面显示回退状态；工程仍保留原字体名，重新安装后可恢复。
- Motion artifact 无法解码时，画布编辑保持禁用，并沿用现有错误状态，不伪装成透明动画。

### 7.3 本轮不做

- 不增加系统级独占全屏窗口。
- 不在画布中编辑 Remotion 内部文字、颜色或关键帧；这些继续通过 Remotion 配置和 Codex 修改。
- 不增加透视变形、自由四角拉伸或画布旋转手柄。
- 不重做统一的普通文字与字幕编辑引擎。

## 8. 验收与行为测试

### 8.1 字幕

- 改字重后字体族不变；同一字幕可观察到真实粗细变化。
- 三种随应用字体至少各完成一次预览与导出一致性检查。
- 字间距、描边宽度和阴影参数在 GPU 预览与导出帧中一致。
- 旧工程加载后视觉默认值不突变。
- 中文模式下字幕面板不存在面向用户的遗漏英文；技术值除外。

### 8.2 播放器

- 进入和退出大屏不重新初始化 canvas，播放时间连续。
- 拖动进度条可准确 seek；长工程拖动不形成明显事件积压。
- 点击画布切换播放，但拖动字幕或 Motion 控制点不会误触播放。
- `Esc` 和空格键行为正确。

### 8.3 Motion 画布

- 拖动与缩放即时反映到预览，保存重开工程后仍在原位置。
- 最终导出帧与预览位置、大小一致。
- transform 修改不改变 artifact 状态，也不触发 Remotion 重新渲染。
- 多个不同角色覆盖时可编辑顶层，也能通过时间轴选中下层。
- 单次拖动只产生一次可撤销操作。

## 9. 保护项

- 不清理、覆盖或提交当前工作树中与本轮无关的未提交改动。
- 不改变 Cap 原始录制媒体、ASR、字幕导入、EDL、Motion 时间轴互斥和项目热加载的既有行为。
- 不引入 Remotion 以外的程序动画运行链。
- 不在未经用户明确要求时启动或抢占 Cap 窗口。
