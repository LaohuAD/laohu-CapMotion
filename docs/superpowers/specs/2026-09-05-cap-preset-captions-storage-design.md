# Cap 预设、字幕位置、入场动画与存储位置设计

## 目标

修复 Cap 局部补丁造成的四类不一致，让界面手工编辑、命名预设、Agent 读取、字幕渲染与工程存储最终共用同一份稳定数据。

## 1. 命名预设的差量保存

- 用户可在工程中先手工修改字体、字号、描边、阴影、位置等公开可编辑展示参数，再直接选择“保存已更改的设置”。
- 保存不再依赖“本次打开编辑器后必须先应用预设”这个内存状态。
- 编辑器记录本次编辑会话内实际改变过的公开展示字段；保存时只允许这些白名单字段进入目标预设。禁止把“当前工程与目标预设的所有差异”当成用户本次修改。
- 其他字段保持已存值，尤其不得覆盖 `agentProfile`、字幕正文、素材路径、剪辑时间轴、音轨、Remotion 资产和工程 revision。
- 若 Agent 或其他窗口在同期修改了预设中的其他字段，当前保存只合并用户改动的字段，不回滚外部更新。

## 2. 字幕轨道级位置

- 手动位置用字幕中心点表示，画面正中心显示为 `X=0, Y=0`。
- 工程内部仍使用 0–1 归一化坐标，界面显示为以 1920×1080 输出画布为基准的中心像素坐标。这样方向键的 `±1` 就是 1 个输出像素，同时预设跨预览缩放和不同显示器保持稳定。
- 选择“手动”后显示 X/Y 数字框；数字修改、画布拖动和方向键移动双向同步。按住方向键使用系统键盘重复，单次步进 1 像素。
- 一条字幕轨道共用一组位置，不再将拖动结果只写入当前某一条字幕。中文和英文轨道可分别保存位置。
- 除字幕正文与时间外，字体、大小、颜色、描边、阴影、字距和动画默认作用于选中轨道的全部字幕。

## 3. 只有入场的字幕动画

- 公开选项至少包含：无动画、渐显、上移弹入、弹入。不提供出场动画选项。
- 所有选项只在字幕开始时生效；到达字幕结束时立即切换，不淡出、不缩小、不下落。
- 无动画始终为 100% 透明度和 100% 缩放。
- 渐显只改变透明度；上移弹入改变 Y 位移并轻微回弹；弹入改变缩放并轻微回弹。三者必须在自动截帧对比中有明显不同。

## 4. 用户可选的工程与媒体存储位置

- 在“设置 → 存储位置”保留单一目录选择。
- 选择后，新建的录制工程、截图工程以及工程使用的导入图片存入该位置。
- 小型设置文件、日志和必要缓存仍留在 Application Support，不将“选择媒体目录”误解为搬走整个应用数据目录。
- 旧工程不强制迁移，仍可在工程库中打开；用户主动选择迁移时才移动。
- 设置值持久化后，录制创建、截图创建、导入图片和工程列表扫描都通过同一个路径解析器，避免界面显示一个目录而后端仍写默认目录。

## 验收

1. 未先应用预设也能直接保存当前变更，只修改白名单字段，`agentProfile` 与工程内容不变。
2. 中文或英文轨道任意一条字幕被拖动后，该轨道全部字幕位置一致，另一轨道不变。
3. X/Y 输入、拖动和方向键相互同步，中心点显示 0/0。
4. 四种入场动画在开始帧可区分，结束帧都没有出场过渡。
5. 选择非系统盘目录后，新录制、新截图和新导入图片不再增加默认 recordings/screenshots 目录的大文件。
