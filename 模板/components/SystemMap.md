# SystemMap

## 任务

解释一个中心概念与多个模块之间的层级、包含或网络关系。

## Modes

`hub-spoke` / `hierarchy` / `inclusion` / `network` / `radial`

## 输入边界

- 3-8 个外围模块。
- 中心标题必须是共同上位概念。
- 网络模式只有在关系不是单纯顺序时使用。

## 适用

系统全貌、能力地图、模块拆解、包含关系和多因素影响。

## 禁用

有明确先后顺序的内容优先使用 FlowNodeGraph 或 TimelineRoadmap。

## 质检

中心与外围不重叠；连接线不穿过文字；外围模块分布均衡；不能出现半边空。
