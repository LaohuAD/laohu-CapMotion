# Bundled caption fonts

`scripts/setup-caption-fonts.mjs` downloads the pinned font binaries and verifies
their SHA-256 digests before Rust compilation. The generated `.ttf` files are
ignored by Git; their licenses remain tracked here.

- Source Han Sans / Source Han Serif: SIL Open Font License 1.1
- LXGW WenKai: SIL Open Font License 1.1
